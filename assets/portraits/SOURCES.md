# Portrait sources

Example portraits for the character-creation pickers (races, classes,
backgrounds). These 39 bust portraits were generated for this site with
an AI image model (via the keyless Pollinations API, Flux model) from
prompts naming each race, class, or background — consistent painterly
style, centered busts on plain dark backgrounds, 384x384 JPEGs.

Because they are original generated pixels made for this project (not
copies of anyone's artwork), there is nothing to attribute and no
license to comply with — they are safe to use on this non-commercial
site. Files live next to this document; nothing is hotlinked. The
generation script (prompts plus seeds, so any image can be
reproduced) is `scripts/gen-portraits.py`.
