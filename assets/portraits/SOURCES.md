# Portrait sources

Example portraits for the character-creation pickers (races,
subraces, classes, subclasses, backgrounds). These 167 bust
portraits were generated for this site with an AI image model (via
the keyless Pollinations API, Flux model) from prompts naming each
race, class, subclass, or background — consistent painterly style,
centered busts on plain dark backgrounds, 384x384 JPEGs. Subclass
prompts name the subclass plus its two signature features, so each
of the 116 subclass portraits carries its own motif; seeds are
fixed per portrait, so any image can be reproduced.

Because they are original generated pixels made for this project (not
copies of anyone's artwork), there is nothing to attribute and no
license to comply with — they are safe to use on this non-commercial
site. Files live next to this document; nothing is hotlinked.
Generated images carry a small Pollinations service watermark in one
corner.
