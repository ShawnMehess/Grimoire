# Subclass gaps — unsourced feature grants

Every feature grant below has neither an entry in
`data/subclass-feature-summaries.json` nor rules text fetched from
dnd5e.wikidot.com, so it renders with NO mechanics text — omitted from
player-facing display until sourced — per
docs/SUBCLASS-CONTENT-AUDIT-2026-09.md §2b. One line each: feature id,
subclass name, level, what's missing.

Two sources count as sourced:

- `data/subclass-feature-summaries.json` — hand-written summaries.
- `js/data/subclassFeatureText.js` — GENERATED by
  `scripts/fetch-subclass-feature-text.mjs` (scrapes the subclass page
  and records the URL on every grant it fills). These grants are the
  bulk of what closed: 566 of 640 now have text, up from 59.

The reason so many needed scraping at all: the subclass export in
docs/New Info was taken from the ACTOR, so each feature was a bare
`@Compendium[...]{Name}` reference with no prose. The feats export was
taken from the compendium and carries its text, which is why feats always
had descriptions and subclasses did not.

Total unsourced: 0 of 636 grants (636 sourced).

Regenerate (never hand-edit the list below):
`node scripts/gen-subclass-gaps.mjs [--class <Class>]`
